# Streamline "Pixel" icons (CC BY 4.0)

This folder is intentionally empty. It is the only place a Streamline Pixel icon may live.

On 2026-09-23 the set page (https://www.streamlinehq.com/icons/pixel) still states "Licensed
under the Creative Commons - CC BY 4.0", but its structured data links the proprietary
Streamline Free License, and the SVG files are not downloadable without a Streamline account.
The project therefore applied the SPEC §10.5 fallback: every icon is custom pixel art under
`design/icons/custom/` (MIT). See `docs/design.md` for the decision record.

If an icon is added here later, it must be from the Pixel set, keep the CC BY 4.0 license, and
be recorded in `THIRD_PARTY_NOTICES.md` with the attribution line
"Pixel icons by Streamline (https://www.streamlinehq.com), from the "Pixel" set, licensed under
CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Changes: recolored to `currentColor`
and optimized."
