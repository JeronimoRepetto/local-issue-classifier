Triage GitHub issues, rated by an AI you control.

Issue Classifier pulls a GitHub repository's open issues and README, then rates each one by criticality, complexity, effort and relevance to your project.

Ratings come from Jev (TypeSafe AI's decision model), a local model server such as Kev, or a model running entirely inside your browser. Your GitHub token and any API keys stay in this browser tab; nothing is sent anywhere except the rating request itself.

  • Filter and sort issues by weighted priority
  • Dismiss issues that do not need attention
  • Export the results as plain text
